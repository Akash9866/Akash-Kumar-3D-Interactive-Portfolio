## 🏛️ Architectural Experience & Features

- **Continuous 3D Spatial Gallery**: A unified Three.js environment that smoothly navigates through 9 architectural chambers (Welcome Atrium, About Me, Core Capabilities, Internships, Projects, Research & Publications, Startups & Ventures, Experience, and Contact Portal).
- **Hybrid Physical Signage & Glass Displays**: 3D structural wall signage and semi-transparent physical digital display screens anchored in 3D world space.
- **Dedicated Subpages**: Comprehensive deep-dive pages for `/about`, `/internships`, `/projects`, `/research`, `/startups`, `/experience`, and `/contact`.
- **Interactive Metrics & Analytics**: Visual ROI graphs, conversion charts, and interactive case study modals.
- **Optimized for Cloudflare**: Pre-configured SPA rewrite rules (`_redirects`), custom edge headers (`_headers`), and one-command deployment (`npm run deploy`).

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20+ recommended)
- npm or bun

### Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Akash9866/Akash-Kumar-3D-Interactive-Portfolio.git
   cd Akash-Kumar-3D-Interactive-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Deployment to Cloudflare Pages

To deploy updates to Cloudflare Pages directly:

```bash
npm run deploy
```

This compiles the static distribution with Vite into `dist/` and uploads it to the `akashkumar` project on Cloudflare Pages.
